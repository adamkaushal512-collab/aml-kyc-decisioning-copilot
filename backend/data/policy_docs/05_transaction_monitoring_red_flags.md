# Policy AML-045: Transaction Monitoring Red Flags for Structuring and Large Wires

**Scope:** Applies to all transaction monitoring alerts generated from
wire transfers, cash deposits, and related payment activity.

## Clauses

1. If a customer conducts multiple transactions just below a regulatory or
   internal reporting threshold within a short period (e.g., several
   transactions between $9,000 and $9,999 within a 7-day window), the
   pattern must be flagged as potential structuring for analyst review.

2. If a single wire transfer exceeds $1,000,000, or an international wire
   transfer exceeds $250,000, the transaction is automatically flagged for
   enhanced review regardless of the customer's prior transaction history.

3. If a customer's transaction volume or size deviates significantly from
   their documented profile (e.g., a personal account with no prior large
   activity suddenly sending international wires exceeding $500,000), the
   deviation must be flagged and investigated before the transaction is
   cleared.

4. If a wire transfer involves a jurisdiction designated as high-risk or
   non-cooperative for AML purposes, the transaction must be flagged for
   enhanced review even if it falls below the standard dollar thresholds
   in Clause 2.

5. If a flagged transaction cannot be reasonably explained by the
   customer's known business or personal activity, the case must be
   escalated in line with SAR filing requirements (Policy AML-032).

6. Analysts must document the specific red flag(s) triggered and the
   evidence considered when clearing or escalating a flagged transaction;
   flags may not be dismissed without a recorded rationale.
